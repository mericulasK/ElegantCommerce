# Project Migration from Replit Agent to Replit

## Overview
This is an e-commerce application built with React frontend and Express backend, using TypeScript, Tailwind CSS, Drizzle ORM, and PostgreSQL. Currently migrating from Replit Agent environment to standard Replit environment.

## Architecture
- **Frontend**: React with Vite, Wouter for routing, TanStack Query for data fetching
- **Backend**: Express.js API server with TypeScript
- **Database**: PostgreSQL with Drizzle ORM
- **UI**: Shadcn/ui components with Tailwind CSS
- **State Management**: TanStack Query for server state

## Current Migration Status
- Project has full-stack JavaScript setup
- All dependencies are installed
- Workflow configured for `npm run dev`
- Database schema defined in shared/schema.ts
